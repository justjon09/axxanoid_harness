# SKILL: memory_retrieval

When the CEO asks a question referencing past conversations or historical context not present in your immediate memory, you must retrieve it.

1. Use the `chat_search` tool to query the chat history.
2. Provide a specific `keyword` to locate the relevant past context.
3. Set the `limit` parameter to define how many past messages to return.
4. Once the historical context is returned, use it to reply directly to the CEO.
